# Python Control Flow - Assignment 2

## Description

This assignment demonstrates the basic use of Python control flow concepts, including 'conditionals', 'loops', 'break', and 'continue'.

## Tasks

### Task 1 - Discount Rules

Created a program that takes an order amount from the user and applies a discount based on the order value.

- 2000 or more → 15% discount
- 1500–1999 → 10% discount
- 1000–1499 → 7% discount
- Below 1000 → No discount

### Task 2 - Process Multiple Orders

Created a list of order amounts and used a 'for loop' to apply discount rules to each order. Also calculated the total revenue after discounts.

### Task 3 - User Menu

Created a simple 'while loop' driven menu that allows the user to:

1. Add an order amount to a list
2. Show all orders and their final amounts after applying discounts
3. Quit the program using 'q'

Used 'break' to exit the loop.

### Task 4 - Loop Control with Conditions

Processed a list of daily sales using a 'for loop'.

- '-1' → Treated as corrupted data and stopped processing using 'break'.
- '0' → Treated as a day with no sales and skipped using 'continue'.
- Positive values → Added to total sales and displayed the running total.

## Concepts Used

- 'if', 'elif', 'else'
- 'for loops'
- 'while loops'
- 'break'
- 'continue'
- Lists
- User input
- Basic arithmetic operations
