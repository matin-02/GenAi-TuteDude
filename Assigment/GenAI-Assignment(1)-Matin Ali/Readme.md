Python Data Structures - Assignment 1
Description

This assignment demonstrates the basic use of Python data structures: Lists, Tuples, Sets, and Dictionaries.

Tasks
Task 1 - Product Collections

Created a list of products and a tuple containing product name, price, and category. Also demonstrated adding products to a list.

Task 2 - Categories

Created a set of categories and demonstrated adding categories, ignoring duplicates, and checking whether a category exists.

Task 3 - Product Pricing

Created a dictionary containing product names and prices. Demonstrated adding, updating, and removing products and calculated the average price.

Task 4 - Combined Operations

Combined the product list, price dictionary, and categories to create a catalog. Products were grouped by category, and the category containing the maximum number of products was displayed.

Run each Python file separately using Python 3.

Conclusion

The assignment demonstrates how Python data structures can be used to manage and organize simple e-commerce product information.
